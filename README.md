# timelogTrans · 工作时间同步

Android 上读取「时间日志」本地自动备份，按“工作”分类的子分类统计时长，一键将周、自然月摘要同步到飞书多维表格。时间记录、原始事件和备注不会上传。

当前版本：**0.9-device-transfer**，Android 8.0 及以上。手机独立运行，无需服务器、USB 调试或开发者模式。当前采用手动一键同步，无后台定时任务。

## 手机使用

1. 安装使用自己部署配置编译的 APK。
2. 在时间日志中开启本地外部自动备份，确认当前备份实际存储位置。
3. 点击“连接时间日志”，通过系统目录选择器授权当前备份账号目录。默认目录可调整，不要选择多年未更新的旧副本；应用只能在已授权目录内查找备份。
4. 点击“连接飞书”，输入专用自建应用 App Secret。App ID 由构建配置预填；连接验证通过后凭证以 Android Keystore 加密保存在手机。
5. 点击“同步本周”。首页显示本周、本月小时数、实际已记录数据截止时间、备份更新时间和同步阶段。

已有安装更新时沿用目录授权和加密凭证。首次系统授权仍需本人确认。

## 统计及覆盖规则

- 时区 Asia/Shanghai；本周为周一零点至本次汇总时刻，本月为自然月一日至汇总时刻。
- 仅统计备份中已结束的工作时段；未触发时间日志自动备份的新记录无法读取。跨周、跨月时段按边界裁剪。
- 分类根名称为“工作”，按其第一层子分类汇总，直接挂在工作根下的记录记为“未细分工作”。工作记录重叠、分类循环或备份异常时停止处理。
- 唯一键为 `周或月 / 周期起始日期 / 工作板块`。同周重新同步更新旧结果，绝不累加；消失板块归零，历史周期保留。周、月不会互相覆盖。
- 云端备份时间或汇总截止更新时默认拒绝覆盖。迁移常用设备可在冲突预览中明确确认，使用预览时同一份周/月快照替换；默认保护不会永久关闭。
- 每次写入后读回核对。当前设计为单一常用设备上传，不提供多设备并发一致性保证。

## 飞书结构

一个 Base，一张汇总表，一个包含周/月饼图及两个独立日期切片器的看板。应用身份至少具有记录读取、创建、更新权限，并被授予该 Base 编辑权限。

| 字段 | 类型 |
| --- | --- |
| 同步键 | 文本，主字段 |
| 周期类型 | 文本：周或月 |
| 周期起始日期 | 文本：YYYY-MM-DD |
| 工作板块 | 文本 |
| 时长小时 | 数字 |
| 占工作时间百分比 | 数字，百分比显示，实际存储0–1 |
| 周期总时长小时 | 数字 |
| 备份时间、同步时间、汇总截止时间 | 日期时间 |

看板日期辅助公式为 `TODATE([周期起始日期])`。周图限定周期类型为周、月图限定为月，均按工作板块分组并 SUM 时长小时、排除零值；各日期切片器只关联对应图。筛选以整周/自然月摘要为单位，不支持任意几天重新核算。仓库不包含个人看板配置或历史迁移脚本。

## 本地构建（Windows）

依赖 Python 3、JDK 21、Android SDK Platform 35 / Build Tools 35.0.0。SDK、org.json jar 和签名密钥均自行准备，不随源码分发。

1. 将 `deployment.example.json` 复制为 `deployment.local.json`，填写四项公共部署坐标。**不要填写 App Secret**。
2. 配置环境变量，然后执行：

```powershell
$env:JAVA_HOME = 'C:\path\to\jdk-21'
$env:ANDROID_SDK_ROOT = 'C:\path\to\Android\Sdk'
python android/build.py
```

产物：`android/build/work-time-sync-validation.apk`。构建时从本地配置生成 Deployment.java；本地配置、生成文件及产物被 Git 排除。生成的 APK 包含部署坐标，不包含 App Secret。

本地默认生成开发签名。**升级现有设备必须使用原签名密钥**；保留现有本地密钥，并通过 `WORKTIME_KEYSTORE` 指向它。当前签名流程仅用于既有开发签名，正式商店发布需另行完善发布签名，不要将密钥提交到仓库。

```powershell
$env:JSON_JAR = 'C:\path\to\json-20240303.jar'
python android/test.py
```

覆盖备份目录选择、自然月合并、同周覆盖与移除板块、幂等重试、旧版本保护、跨设备确认替换及云端读回异常。真实手机目录授权、飞书权限和原生界面仍需实机验收。

`export_backup.py` 可离线只读核算个人备份；输出保留本地，勿提交。真实数据已验证周/月合计、板块时长和占比一致，验收原始数据不随源码公开。
